# HeapTracker Pass

An LLVM pass for tracking memory operations in unsafe Rust code blocks. This pass identifies loads and stores within blocks marked by InstMarker and instruments them with runtime calls for analysis.

## Core Functionality

- **Memory Access Tracking**: Instruments memory loads and stores within unsafe blocks
- **Unsafe Block Detection**: Uses the assembly markers generated by InstMarker pass
- **Runtime Integration**: Calls into a Rust runtime to report memory operations

## Implementation Details

The pass looks for the inline assembly markers inserted by the InstMarker pass to identify unsafe code blocks. For each memory operation (load/store) within these blocks, it inserts a call to the `dyn_unsafe_mem_access` runtime function.

## Integration

This pass builds on top of the InstMarker pass:
- InstMarker marks unsafe blocks with assembly markers
- HeapTracker uses these markers to identify where to instrument memory operations

## Usage

### Compiler Integration
```bash
# Enable CpuCycleCount
rustc --emit=llvm-ir \
  -C llvm-args=-enable-heap-tracker \
  -Z unstable-options \
  --extern force:unsafe_perf=/home/oscar/Projects/unsafebench/unsafebench-expr/lib/perf/target/release/deps/libunsafe_perf-9c644cd274fb6d62.rlib \
  -L/home/oscar/Projects/unsafebench/unsafebench-expr/lib/perf/target/release/deps
```

This pass can also be integrated into the Rust compiler pipeline by adding appropriate flags to rustc.

## Runtime Requirements

The pass expects a runtime function with the following signature:
```c
void dyn_unsafe_mem_access(void* ptr, bool isLoad);
```

This function should be provided by the host application or a runtime library.
